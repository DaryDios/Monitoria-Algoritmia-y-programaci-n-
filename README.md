## 📌 Introducción

En este trabajo se presentan diferentes conceptos básicos de programación en **Python**, utilizando ejemplos prácticos para comprender el funcionamiento de los **operadores lógicos**, las **estructuras condicionales** y los **ciclos**.

Durante el desarrollo se utilizan operadores como `AND`, `OR` y `==`, relacionándolos con conceptos matemáticos como la **intersección** y la **unión de conjuntos**. También se desarrollan ejercicios utilizando estructuras `if`, `else` y ciclos `for` para resolver situaciones sencillas, como la validación de una temperatura y la búsqueda de personas dentro de una lista.

Además, se aplican algunas recomendaciones de estilo de Python, como **PEP 8** y **PEP 257**, con el propósito de mantener un código organizado, claro y fácil de comprender.

### 🎯 Objetivo

Comprender y aplicar los principales operadores lógicos y estructuras de control de Python mediante ejercicios prácticos, relacionando su funcionamiento con conceptos de lógica y conjuntos.
